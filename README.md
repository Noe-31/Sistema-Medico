Sistema Web de Gestión Médica

Sistema completo de gestión médica desarrollado con **HTML5, CSS3 y JavaScript puro**. 

## ✨ Características

✅ **Autenticación** - Login seguro (Demo: admin/admin)  
✅ **Gestión de Pacientes** - Crear, editar, eliminar pacientes  
✅ **Gestión de Citas** - Programar y seguimiento de citas  
✅ **Historia Médica** - Registro de diagnósticos y tratamientos  
✅ **Calendario Interactivo** - Vista de citas en calendario  
✅ **Dashboard** - Gráficas y estadísticas en tiempo real  
✅ **Reportes** - Exportar en JSON, CSV y PDF  
✅ **Dark Mode** - Tema oscuro/claro con persistencia  
✅ **Responsive Design** - Se adapta a cualquier dispositivo  
✅ **Búsqueda y Filtros** - Buscar y filtrar datos fácilmente  
✅ **Notificaciones** - Feedback en tiempo real  
✅ **LocalStorage** - Persistencia de datos sin servidor  

## 🚀 Tecnologías

- **HTML5** - Estructura semántica
- **CSS3** - Diseño moderno y responsive
- **JavaScript Vanilla** - Sin frameworks pesados
- **Bootstrap 5** - Framework CSS
- **Chart.js** - Gráficas y estadísticas
- **FullCalendar** - Calendario interactivo
- **jsPDF** - Exportación a PDF
- **Font Awesome** - Iconos
